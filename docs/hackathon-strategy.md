# NASA Space Apps demo story

**Problem:** configuration choices need transparent trade-offs before a mission decision. **User:** a mission-planning team exploring low-Earth-orbit configurations. **System:** OrbitGuard turns three supplied configuration values into circular-orbit estimates, explainable heuristic signals, scenario deltas, and persisted decision snapshots.

Suggested demo: create a baseline mission → explain the current deterministic score and modeled environment → propose a changed configuration → compare only what changed under the same rules → record a human decision with rationale → apply an approved scenario → show the pending-review reassessment and history.

The innovation is traceability and explainability across the decision loop, not a claim of operational conjunction assessment.
